# Claude skill: Intraday Paper Lab

This skill is available to Claude Code when the repository is checked out, provided the skill directory is installed/discovered by the user's Claude Code setup.

Skill path: `.claude/skills/intraday-paper-lab/SKILL.md`.

It guides Claude through understanding, testing, and safely extending the repository's backtester, performance dashboard, and simulated feed. It does not enable real-money trading or provide a live broker integration.

To use it, open this repository in Claude Code and ask for work related to the intraday paper-trading project; Claude can then apply the skill's instructions. If using a Claude product or setup that does not load project-local skills, copy the skill directory into that setup's supported skills location or paste the `SKILL.md` contents as project instructions.
