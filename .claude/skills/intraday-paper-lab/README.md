# Claude skill: Intraday Paper Lab

Skill project-local: `.claude/skills/intraday-paper-lab/SKILL.md`.

La skill completa comprende checklist, architettura, ricerca quant/ML/LLM supervisionata, risk management multi-asset, requisiti per API esclusivamente mock/paper sandbox, grafici e formato di risposta. Usa `SKILL.md` come istruzione principale e consulta i riferimenti collegati quando pertinenti.

Apri il repository con Claude Code e chiedi un'attività nel progetto. Se l'ambiente Claude non carica le skill project-local, installa la directory nella posizione di skill supportata da quell'ambiente o passa `SKILL.md` come istruzione di progetto.

La skill non aggiunge una connessione broker concreta: prima servono provider e documentazione ufficiale, e l'adapter deve restare in sandbox/paper. Non autorizza né implementa ordini reali.
